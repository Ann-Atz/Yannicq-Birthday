# Yannicq-Birthday

A fun birthday gift website.

## Start the website locally

### Requirements

- [Python 3](https://www.python.org/downloads/) installed
- A modern web browser

### macOS or Linux

1. Open Terminal and move to the project folder:

   ```sh
   cd /path/to/Yannicq-Birthday
   ```

2. Start a local web server:

   ```sh
   python3 -m http.server 8000
   ```

3. Open <http://localhost:8000> in a browser.

### Windows

1. Open Command Prompt or PowerShell and move to the project folder:

   ```powershell
   cd C:\path\to\Yannicq-Birthday
   ```

2. Start a local web server:

   ```powershell
   python -m http.server 8000
   ```

3. Open <http://localhost:8000> in a browser.

### In VS Code

Install the **Live Server** extension, open `index.html`, then click **Go Live** in the VS Code status bar.

Keep the terminal running while using the site. Press `Ctrl+C` to stop the server.
